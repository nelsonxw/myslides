# PROJECT: MySlides— AI-Powered Slide Builder from Curated Templates

## 1. PROJECT OVERVIEW

**Objective:** Build a web application that ingests a user's curated PowerPoint slide collection, catalogs all diagrams, charts, and layouts, and uses that catalog as a foundation to generate new slides from natural language prompts — automatically suggesting and applying the most appropriate visual elements from the collection.

## 3. FUNCTIONAL REQUIREMENTS

### MODULE 1: Slide Ingestion & Cataloging Pipeline

**FR-1.1: PPTX Upload & Parsing**
- Accept single or batch `.pptx` file uploads
- Use `python-pptx` to parse each slide and extract:
  - Layout type (title slide, content slide, section divider, blank, etc.)
  - Shapes (rectangles, arrows, chevrons, circles, custom shapes with geometry)
  - Charts (bar, line, pie, combo, waterfall, etc.) including chart type, data structure, axis configuration
  - SmartArt / Diagrams (process flows, cycles, hierarchies, matrices, pyramids, funnels, timelines, Venn diagrams)
  - Tables (structure: rows, columns, header styling)
  - Images (extract and store as assets, generate visual embeddings)
  - Text content (titles, subtitles, body text, callouts, labels)
  - Styling metadata (color palette as hex values, font families, font sizes, fill colors, border styles, transparency, shadow effects)
  - Positioning data (x, y, width, height in EMUs for every element)
  - Groupings (which shapes are grouped together to form a composite diagram)
  - Slide dimensions and aspect ratio

**FR-1.2: Slide Classification**
- Automatically classify each slide into a category using a combination of heuristics and LLM analysis:
  - `title_slide`
  - `agenda`
  - `section_header`
  - `text_heavy` (bullet points, paragraphs)
  - `comparison` (side-by-side, vs.)
  - `process_flow` (linear, branching)
  - `timeline`
  - `org_chart` / `hierarchy`
  - `data_chart` (with sub-type: bar, pie, line, etc.)
  - `matrix` / `quadrant`
  - `funnel`
  - `pyramid`
  - `dashboard` (multiple charts)
  - `image_showcase`
  - `table_view`
  - `mixed` (combination of elements)
- Allow users to manually override or refine classification
- Store classification as metadata

**FR-1.3: Template Extraction & Storage**
- For each cataloged slide, create a template record containing:
  - Unique template ID
  - Classification category and tags
  - Thumbnail image (rendered PNG of the slide)
  - Original `.pptx` slide reference (file name + slide index)
  - Element manifest (structured JSON of all shapes, positions, styles)
  - Placeholder map (which text/data fields are variable vs. decorative)
  - Color palette extracted (primary, secondary, accent colors)
  - Complexity score (number of elements, nesting depth)
- Store templates in a structured database

**FR-1.4: Visual & Semantic Embedding Generation**
- Generate a visual embedding for each slide thumbnail using a vision model (e.g., CLIP or OpenAI Vision)
- Generate a semantic embedding for each slide based on:
  - Classification category
  - Element types present
  - Text content / labels
  - A natural language description auto-generated by an LLM examining the slide structure
- Store embeddings in a vector database (Pinecone, Weaviate, pgvector, or ChromaDB)

### MODULE 2: Prompt Interpretation Engine

**FR-2.1: Natural Language Prompt Parsing**
- Accept user prompts such as:
  - "Create a slide showing our 5-step onboarding process"
  - "Build a comparison slide for Plan A vs Plan B pricing"
  - "Show quarterly revenue as a bar chart with a trend line"
  - "Make a timeline of our product milestones from 2020 to 2025"
- Use an LLM to extract structured intent:

```json
{
  "slide_type": "process_flow",
  "content": {
    "title": "5-Step Onboarding Process",
    "steps": ["Application", "Screening", "Interview", "Offer", "Orientation"]
  },
  "data_type": null,
  "element_preferences": ["chevron_arrows", "numbered_steps"],
  "color_preference": null,
  "tone": "professional"
}
```

**FR-2.2: Multi-Slide Prompt Support**
- Support prompts that request a deck (multiple slides):
  - "Create a 10-slide pitch deck for a fintech startup"
- LLM should break this into individual slide intents with a logical flow
- Return a structured slide plan for user confirmation before generation

**FR-2.3: Contextual Follow-Up**
- Support conversational refinement:
  - "Change the chart to a pie chart instead"
  - "Use the blue color scheme from my uploaded slides"
  - "Add a callout box highlighting step 3"

### MODULE 3: Template Matching & Suggestion Engine

**FR-3.1: Template Retrieval**
- Given the structured intent from Module 2, query the vector database to find the top 3–5 most relevant templates from the user's catalog
- Matching criteria (weighted):
  - Slide category match (highest weight)
  - Element type match (e.g., prompt asks for timeline → templates with timeline shapes)
  - Content structure similarity (e.g., 5 items → templates designed for 5 elements)
  - Semantic similarity of description embeddings
  - Visual similarity if user provides a reference image

**FR-3.2: Suggestion Presentation**
- Present matched templates to the user as:
  - Thumbnail previews
  - Match confidence score (percentage)
  - Brief description of why it was selected
- Allow user to select preferred template or request more options

**FR-3.3: Adaptive Element Count**
- If the matched template has 4 process steps but the user needs 5:
  - Automatically adapt the template layout (add/remove shape copies, adjust spacing proportionally)
  - Preserve styling and relative positioning

### MODULE 4: Slide Generation Engine

**FR-4.1: Template-Based Assembly**
- Using the selected (or auto-selected) template and the structured content:
  - Clone the template slide structure
  - Replace placeholder text with user's content
  - Populate chart data if applicable
  - Adjust element count as needed (FR-3.3)
  - Apply user's content while preserving original styling

**FR-4.2: Chart Generation**
- Support programmatic creation of:
  - Bar charts (vertical, horizontal, stacked, grouped)
  - Line charts (single, multi-series)
  - Pie / Donut charts
  - Combo charts (bar + line)
  - Waterfall charts
  - Area charts
- Accept data input as:
  - Inline in the prompt ("Revenue: Q1=100, Q2=150, Q3=200, Q4=180")
  - CSV / Excel file upload
  - Manual table entry in the UI

**FR-4.3: Diagram Generation**
- Support programmatic creation of:
  - Process flows (linear, branching)
  - Timelines (horizontal, vertical)
  - Org charts / Hierarchies
  - Cycle diagrams
  - Funnels and pyramids
  - Comparison layouts (2-column, 3-column)
  - Matrix / Quadrant diagrams
  - Venn diagrams
- Base styling on the closest template match from the catalog

**FR-4.4: Style Inheritance**
- All generated slides must inherit the visual style from the user's catalog:
  - Color palette
  - Font families and sizes
  - Shape styling (fills, borders, shadows, rounded corners)
  - Slide background
- Allow user to designate a "master style" from their collection that overrides individual template styles

**FR-4.5: PPTX Export**
- Generate a valid `.pptx` file using `python-pptx`
- Ensure all charts are native PowerPoint charts (editable, not images)
- Ensure all shapes are native and editable
- Support export of single slides or full decks
- Optionally export as PDF for preview

### MODULE 5: User Interface

**FR-5.1: Upload Interface**
- Drag-and-drop zone for `.pptx` files
- Upload progress bar with per-file status
- Post-upload catalog viewer showing all extracted slides as a thumbnail grid
- Ability to tag, re-classify, or delete individual slides from the catalog

**FR-5.2: Prompt Interface**
- Large text input area with example prompt suggestions
- Optional: structured input mode (select slide type → fill in fields)
- "Generate" button that triggers the pipeline
- Loading state with progress indicators

**FR-5.3: Suggestion & Preview Panel**
- Side-by-side view of:
  - Suggested templates (left panel)
  - Generated slide preview (right panel, rendered as PNG or SVG)
- Click-to-select template from suggestions
- Real-time preview update when template selection changes

**FR-5.4: Editing Panel (Post-Generation)**
- Basic inline editing:
  - Edit text content directly
  - Swap chart type
  - Change color scheme (pick from extracted palettes)
  - Adjust element count (add/remove steps, items)
- "Regenerate" button to re-run with modified prompt

**FR-5.5: Deck Builder**
- Canvas showing slide sorter view (thumbnails of all slides in a deck)
- Drag-and-drop to reorder slides
- Add/delete slides
- Export entire deck as `.pptx`

## 4. NON-FUNCTIONAL REQUIREMENTS

**NFR-1: Performance**
- Slide parsing: ≤ 5 seconds per slide
- Prompt-to-suggestion: ≤ 8 seconds
- Slide generation: ≤ 10 seconds per slide
- Full deck (10 slides): ≤ 90 seconds

**NFR-2: Scalability**
- Support catalogs of up to 1,000 slides per user
- Support concurrent users (minimum 50)

**NFR-3: Security**
- All uploaded files stored encrypted at rest
- User data isolated (multi-tenant architecture)
- API keys for LLM services stored securely (environment variables or secrets manager)
- HTTPS only

**NFR-4: File Compatibility**
- Input: `.pptx` (Office 2007+ format)
- Output: `.pptx`, `.pdf`
- Not required: `.ppt` (legacy binary format), Google Slides, Keynote

## 7. API ENDPOINTS (Key Routes)

```
POST   /api/collections/upload         Upload PPTX files
GET    /api/collections                List user's collections
GET    /api/templates                  List/filter cataloged templates
PATCH  /api/templates/{id}            Update classification/tags

POST   /api/generate/parse-prompt      Parse prompt → structured intent
POST   /api/generate/suggest-templates Get template suggestions for intent
POST   /api/generate/create-slide      Generate slide from intent + template
POST   /api/generate/create-deck       Generate multi-slide deck

GET    /api/slides/{id}/preview        Get PNG preview of generated slide
GET    /api/slides/{id}/download       Download generated .pptx
GET    /api/decks/{id}/download        Download full deck .pptx

GET    /api/palettes                   List extracted color palettes
```
